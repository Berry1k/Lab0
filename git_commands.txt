git clone - копирует файл, git status - показывает состояние файлов, git add - добавляет файл, git commit - сохраняет изменения, git push - загружает локальные изменения, git branch - отображает ветки в репозитории, git checkout - переключается на указанную ветку, git init - создает новый репозиторий, git log - показывает историю коммитов, git diff - показывает изменения в файлах без коммита.
